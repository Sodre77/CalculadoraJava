# Calculadora JUnit 5

Projeto Java simples com foco em:

- testes automatizados com JUnit 5;
- práticas de versionamento com Git e GitHub;
- simulação de fluxo colaborativo com branch e merge.

## Estrutura

- `src/main/java/.../Calculadora.java`: implementação da calculadora;
- `src/test/java/.../CalculadoraTest.java`: testes unitários;
- `src/test/java/.../CalculadoraFuncionalTest.java`: teste funcional;
- `src/main/java/.../App.java`: execução simples em linha de comando.

## Como executar os testes

```bash
mvn test
```

## Observação para o trabalho

Este repositório já está preparado para receber commits, criação de branch e merge no GitHub.
